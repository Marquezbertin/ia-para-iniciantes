EXERCÍCIO 01: CONCEITOS FUNDAMENTAIS DE MACHINE LEARNING

Dificuldade: ⭐ Fácil
Módulo: 02 - Machine Learning
Tempo estimado: 15 minutos

══════════════════════════════════════════════════════════════════

🎯 OBJETIVO
Compreender os conceitos básicos de Machine Learning e sua importância.

══════════════════════════════════════════════════════════════════

📖 PROBLEMA

Machine Learning é uma das áreas mais importantes da IA moderna. Vamos entender o que é e por que é tão revolucionário.

══════════════════════════════════════════════════════════════════

📝 TAREFAS PRÁTICAS

Tarefa 1: Defina com suas palavras (5 minutos)
   - Escreva em 3-4 linhas o que é Machine Learning
   - Explique como ele se diferencia de programação tradicional
   - Use uma analogia simples

Tarefa 2: Liste 5 aplicações (10 minutos)
   - Pense em 5 aplicativos ou serviços que usam ML
   - Para cada um, explique:
     * Que tipo de ML usa (supervisionado, não-supervisionado, reforço)
     * O que o ML aprende a fazer

Tarefa 3: Diagrama simples (bonus)
   - Crie um diagrama mostrando como o ML funciona
   - Inclua: dados → treinamento → modelo → previsão

══════════════════════════════════════════════════════════════════

💭 PERGUNTAS DE REFLEXÃO

2. Você acha que ML pode errar? Por quê?

3. Como o ML difere de um programa tradicional?

4. Qual aplicação do ML você mais usa no dia a dia?
