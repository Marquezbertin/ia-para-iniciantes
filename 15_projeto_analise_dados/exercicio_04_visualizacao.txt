Dificuldade: ⭐⭐⭐ Difícil

Tempo estimado: 40 minutos

══════════════════════════════════════════════════════════════════

🎯 OBJETIVO
Criar gráficos para visualizar os dados e comunicar as descobertas.

══════════════════════════════════════════════════════════════════

📖 PROBLEMA

Um gráfico vale por mil palavras. Vamos criar visualizações dos dados com Matplotlib.

══════════════════════════════════════════════════════════════════

📝 TAREFAS PRÁTICAS

Tarefa 1: Configure os gráficos (10 minutos)
   - No Colab, instale/importe:
   ```
   import matplotlib.pyplot as plt
   ```

Tarefa 2: Crie 2-3 gráficos (25 minutos)
   - Escolha os gráficos mais adequados para seus dados:
   * **Gráfico de linha:** tendência ao longo do tempo
   ```
   plt.plot(df['ano'], df['valor'])
   plt.xlabel('Ano'); plt.ylabel('Valor'); plt.title('Tendência')
   plt.show()
   ```
   * **Gráfico de barras:** comparar categorias
   ```
   plt.bar(df['categoria'], df['valor'])
   plt.show()
   ```
   * **Histograma:** distribuição de valores
   ```
   plt.hist(df['coluna'])
   plt.show()
   ```
   - Execute e registre (screenshots)
   - Ajuste títulos e rótulos

Tarefa 3: Interprete (5 minutos)
   - Para cada gráfico, escreva o que ele mostra:
     * O que se destaca?
     * Que tendência/insight aparece?
