📝 TAREFAS PRÁTICAS

Tarefa 1: Crie dados com Pandas (15 minutos)
   - No Colab, execute:

   ```
   import pandas as pd

   dados = pd.DataFrame({
       'aluno': ['Ana', 'Beto', 'Carla', 'Duda'],
       'idade': [14, 15, 14, 16],
       'nota_matematica': [8, 6, 9, 7],
       'nota_ciencias': [9, 5, 8, 8]
   })

   print(dados.head())
   print(dados.dtypes)
   print(dados.describe())
   ```

   - Registre os resultados

Tarefa 2: Explore (15 minutos)
   - Rode e interprete os comandos:
   ```
   print(dados['nota_matematica'].mean())   # média de matemática
   print(dados['nota_ciencias'].max())      # maior nota de ciências
   print(dados[dados['idade'] > 14])         # alunos com mais de 14 anos
   print(dados.sort_values('nota_matematica', ascending=False))  # ordenar
   ```
   - Anote qual aluno tirou a maior nota em matemática
   - Qual a média de cada matéria
