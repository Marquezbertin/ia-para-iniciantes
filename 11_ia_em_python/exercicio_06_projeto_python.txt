📖 PROBLEMA

Vamos criar um projeto completo: um classificador de frutas usando características medíveis, com análise de dados e treinamento de modelo.

══════════════════════════════════════════════════════════════════

📝 TAREFAS PRÁTICAS

Tarefa 1: Crie os dados (10 minutos)
   - No Colab, crie um DataFrame com características de frutas:
   (peso, cor_vermelha, cor_amarela, eh_fruta) — invente valores

   ```
   import pandas as pd
   from sklearn.tree import DecisionTreeClassifier
   from sklearn.model_selection import train_test_split
   from sklearn.metrics import accuracy_score

   dados = pd.DataFrame({
       'peso_g':   [150, 120, 180, 140, 130, 90, 80, 300, 250],
       'vermelha': [1, 1, 0, 0, 1, 0, 0, 0, 0],
       'amarela':  [0, 0, 1, 1, 0, 1, 1, 0, 0],
       'fruta':    [1, 1, 1, 1, 1, 1, 1, 0, 0]
   })
   print(dados.head())
   ```

Tarefa 2: Treine e avalie (15 minutos)
   - Complete o código:
   ```
   X = dados[['peso_g', 'vermelha', 'amarela']]
   y = dados['fruta']
   X_treino, X_teste, y_treino, y_teste = train_test_split(X, y, test_size=0.3, random_state=42)
   modelo = DecisionTreeClassifier()
   modelo.fit(X_treino, y_treino)
   pred = modelo.predict(X_teste)
   print("Acurácia:", accuracy_score(y_teste, pred))
   ```
   - Registre a acurácia (pode ser 100% com dados simples!)

Tarefa 3: Faça uma previsão real (15 minutos)
   - Use o modelo para prever uma fruta nova:
   ```
   nova = [[130, 0, 1]]   # peso 130, amarela, não vermelha (um limão!)
   print(modelo.predict(nova))
   ```
   - Teste novas combinações e veja o que o modelo prevê
   - Peça à IA (ChatGPT) para explicar por que o modelo acertou/errou

Tarefa 4: Documente (10 minutos)
   - Escreva um resumo do projeto:
     * Que dados você criou
     * Como o modelo aprendeu
     * O que descobriu sobre o processo
