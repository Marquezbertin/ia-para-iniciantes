📝 TAREFAS PRÁTICAS

Tarefa 1: Acesse o Colab (5 minutos)
   - Acesse https://colab.research.google.com
   - Crie um novo notebook (Novo notebook)

Tarefa 2: Rode os códigos (20 minutos)
   - Execute cada célula e registre o resultado:

   Célula 1 (soma):
   ```
   print(2 + 3)
   ```

   Célula 2 (variáveis):
   ```
   nome = "Maria"
   idade = 14
   print(f"Oi {nome}, você tem {idade} anos")
   ```

   Célula 3 (lista e loop):
   ```
   notas = [8, 7, 9, 6]
   soma = 0
   for n in notas:
       soma += n
   print("Média:", soma / len(notas))
   ```

   Célula 4 (importar NumPy):
   ```
   import numpy as np
   arr = np.array([1, 2, 3, 4, 5])
   print("Média:", arr.mean())
   print("Soma:", arr.sum())
   ```

Tarefa 3: Modifique (5 minutos)
   - Modifique uma das células:
