## 📋 Sobre o Projeto

Este repositório é um curso completo de Inteligência Artificial para iniciantes, projetado para jovens a partir de 12 anos. Faça parte do ecossistema **Laboratório Tech Social**, uma iniciativa que promove educação tecnológica acessível e inclusiva.

**O que você vai aprender:**
- Conceitos fundamentais de IA e Machine Learning
- Como usar ferramentas de IA no dia a dia
- Prompt Engineering eficaz
- Construir chatbots e projetos práticos
- Ética e responsabilidade no uso da IA

## 🎯 Para quem é?

- Jovens de 12+ anos curiosos sobre IA
- Educadores buscando recursos didáticos
- Qualquer pessoa que queira entender IA do zero
- Sem necessidade de conhecimentos prévios de programação

## 📚 Como Usar Este Curso

1. **Comece pelo módulo 01** e siga a ordem cronológica
2. **Leia a teoria** de cada módulo antes de fazer os exercícios
3. **Pratique** com as ferramentas de IA mencionadas
4. **Refleta** sobre as questões éticas em cada módulo
5. **Compartilhe** seus aprendizados com colegas

### Pré-requisitos
- Computador ou celular com acesso à internet
- Navegador web atualizado
- Conta gratuita em ferramentas de IA (ChatGPT, Claude, etc.)
- Curiosidade e vontade de aprender!

## 📊 Progressão de Aprendizado

```
Módulos 01-05: Fundamentos (O que é IA, ML, Redes Neurais, NLP, Visão)
     ↓
Módulos 06-09: Ferramentas (Prompt, Assistentes, Geração de Texto/Imagens)
     ↓
Módulos 10-11: Técnico (APIs, Python para IA)
     ↓
Módulos 12-13: Contexto (Ética, IA no Cotidiano)
     ↓

```

## 🎓 Como Obter Certificado

1. Complete todos os 15 módulos
2. Resolva todos os exercícios práticos
3. Desenvolva os projetos finais (módulos 14 e 15)
4. Compartilhe seus projetos no GitHub
5. Preencha o formulário de conclusão (disponível em breve)
