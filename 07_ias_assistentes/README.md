# 🤖 Módulo 07: IAs Assistentes

## 🎯 Objetivos de Aprendizado

Ao final deste módulo, você será capaz de:
- Conhecer as principais IAs assistentes (ChatGPT, Claude, Gemini)
- Entender as diferenças entre elas
- Usar cada uma de forma eficaz
- Compreender os limites dessas ferramentas

## 📖 Teoria

### O que são IAs Assistentes?

**IAs Assistentes** (ou assistentes de IA) são chatbots avançados baseados em modelos de linguagem que podem conversar, responder perguntas, escrever textos, ajudar em tarefas e muito mais.

### Principais IAs Assistentes

#### 1. 🔴 ChatGPT (OpenAI)

**Características:**
- Um dos mais populares do mundo
- Criado pela OpenAI
- Baseado na família GPT
- Gratuito e versão paga (Plus)
- Suporta texto, imagens e voz
- Bom para: tarefas gerais, escrita, programação

**Forças:**
- Extremamente versátil
- Muitas linguagens
- Bom para programação
- Integrações com plugins

**Fraquezas:**
- Pode ser genérico às vezes
- Limites na versão gratuita
- Pode "inventar" informações (alucinações)

#### 2. 🟣 Claude (Anthropic)

**Características:**
- Criado pela Anthropic
- Foco em segurança e responsabilidade
- Ótimo para textos longos
- Muito bom em seguir instruções

**Forças:**
- Excelente compreensão de contexto longo
- Seguro e conservador
- Trabalha bem com documentos
- Menos tendência a respostas ofensivas

**Fraquezas:**
- Alguns limites de uso
- Interface mais minimalista

#### 3. 🔵 Google Gemini

**Características:**
- Criado pelo Google
- Integrado com o ecossistema Google
- Multimodal (texto, imagem, áudio)
- Antigo Bard

**Forças:**
- Integração com Google (Gmail, Docs, Maps)
- Multimodal nativo
- Atualizado com o Google Search

**Fraquezas:**
- Pode ser mais limitado em alguns contextos
- Disponibilidade varia

### Comparando as IAs

| Característica | ChatGPT | Claude | Gemini |
|----------------|---------|--------|--------|
| Criador | OpenAI | Anthropic | Google |
| Foco | Versátil | Segurança | Integração Google |
| Textos longos | Bom | Excelente | Bom |
| Programação | Excelente | Muito bom | Bom |
| Multimodal | Bom | Razoável | Excelente |
| Interface | Amigável | Minimalista | Integrada |
| Gratuito | Sim (limitado) | Sim (limitado) | Sim |

### Como Usar Bem as IAs Assistentes

#### 1. Escolha a IA certa para a tarefa
- **ChatGPT:** ótimo geral, programação
- **Claude:** textos longos, documentos, análise
- **Gemini:** tarefas no mundo Google

#### 2. Use prompt engineering (do módulo 6!)
- Estruture bem seus pedidos
- Use contexto e formato

#### 3. Peça esclarecimentos
- Se a resposta não for boa, peça para reformular
- "Explique de outra forma"
- "Seja mais resumido/mais detalhado"

#### 4. Verifique as informações
- IAs podem errar ou inventar
- Sempre confira fatos importantes
- Não confie cegamente

### Boas Práticas

#### Parceria Produtiva 🔎
- Use a IA como assistente, não como substituta
- Use como "rascunho inicial" e depois revise

#### Para Aprender 📚
- Peça explicações passo a passo
- Peça para corrigir seu trabalho, não fazer por você
- Use para treinar conversação

#### Para Criar 🎨
- Brainstorming de ideias
- Esboços de textos
- Planejamento

#### Para Trabalhar 🧑‍💻
- Gerar/refatorar código
- Resumir documentos
- Preparar apresentações

### Limitações Importantes ⚠️

#### 1. Alucinações
- As IAs podem inventar informações falsas com confiança
- Sempre verifique fatos

#### 2. Viés
- Refletem os dados com que foram treinadas
- Podem ter preconceitos

#### 3. Falta de senso comum do mundo real
- Não vivem experiências reais
- Não "entendem" de verdade o que falam

#### 4. Data de corte
- Modelos têm conhecimento limitado a uma data

#### 5. Segurança e privacidade
- Não compartilhe dados sensíveis
- Conheça os termos de uso

### Segurança no Uso 🛡️

**NUNCA compartilhe com a IA:**
- Senhas e dados de login
- Números de documentos (CPF, RG)
- Dados bancários
- Informações médicas pessoais
- Endereço completo
- Informações privadas de outras pessoas

**SEMPRE:**
- Verifique informações importantes
- Use com senso crítico
- Respeite a legislação
- Conheça a privacidade da ferramenta
