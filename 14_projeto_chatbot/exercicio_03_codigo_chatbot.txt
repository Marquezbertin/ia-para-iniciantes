══════════════════════════════════════════════════════════════════

🎯 OBJETIVO
Escrever o código do chatbot com loop de conversa e tratamento de saída.

══════════════════════════════════════════════════════════════════

📖 PROBLEMA

Agora vamos transformar o acesso à API em um chatbot funcional com um loop de conversa.

══════════════════════════════════════════════════════════════════

📝 TAREFAS PRÁTICAS

Tarefa 1: Escreva o código básico (20 minutos)
   - No Colab, escreva e execute o loop do chatbot:
   ```
   import google.generativeai as genai

   genai.configure(api_key="SUA_KEY")
   model = genai.GenerativeModel("gemini-pro")

   print("=== CHATBOT ===")
   print("Digite sua mensagem ('sair' para encerrar)")

   while True:
       user = input("Você: ")
       if user.lower() == "sair":
           print("Chatbot: Até logo!")
           break
       response = model.generate_content(user)
       print("Chatbot:", response.text)
   ```
   - Execute e teste

Tarefa 2: Adicione tratamento (15 minutos)
   - Melhore o código:
     * Trate entradas vazias (se o usuário digitar nada, avise)
     * Adicione um comando "ajuda" que explica como usar
     * Encerre com uma mensagem amigável
   - Teste as melhorias

Tarefa 3: Documente falhas (5 minutos)
   - Registre: o que funcionou, o que quebrou, como corrigiu
